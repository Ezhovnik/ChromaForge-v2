# Воксельный чанк (версия 1)

Структура чанка слоя воксельных регионов.

Значения разделены для повышения эффективности сжатия extRLE8.

Формат файла в BNF (RFC 5234):

```bnf
chunk    = (65536*byte)    индексы блоков (старшие байты)
           (65536*byte)    индексы блоков (младшие байты)
           (65536*byte)    состояния блоков (старшие байты)
           (65536*byte)    состояния блоков (младшие байты)

byte     = %x00-FF         8-битное беззнаковое число
```

65536 — количество вокселей в чанке (16\*256\*16)

## Block state

Состояние блока кодируется 16 битами:

- 0-2 bits (3) - индекс поворота блока;
- 3-5 bits (3) - биты сегмента блока;
- 6-7 bits (2) - зарезервированы;
- 8-15 bits (8) - пользовательские биты.

# Протокол CHROMA-DBG v1

## Примечания

- «?» в имени означает, что атрибут опционален.

## Подключение

### Шаг 1

Подключение инициируется обменом двоичными заголовками:

```text
'c' 'h' 'r' 'o' 'm' 'a' '-' 'd' 'b' 'g' NUL XX
63  68  72  6f  6d  61  2D  64  62  67  00  XX
```

XX — номер версии протокола

Клиент отправляет заголовок серверу. Затем сервер отвечает.
Сервер закрывает соединение после отправки заголовка, если он не совпадает.

### Шаг 2

Клиент отправляет команду «connect».

## Сообщения

Сообщение состоит из:

- 32-битное беззнаковое целое (little-endian) — количество байтов закодированного сообщения.
- само сообщение (UTF-8 JSON).

## От клиента к серверу

### Установление соединения

```json
{
    "type": "connect",
    "?disconnect-action": "resume|detach|terminate"
}
```

Настройка соединения. Disconnect-action — действие, которое отлаживаемый экземпляр должен выполнить при закрытии/отказе соединения с клиентом отладки.

- `resume` — возобновить из режима паузы и начать прослушивание клиента.
- `detach` — возобновить из режима паузы и остановить сервер.
- `terminate` — остановить отлаживаемое приложение.

### Сигналы конкретных действий

```json
{
    "type": "pause|resume|terminate|detach"
}
```

### Управление точками останова

```json
{
    "type": "set-breakpoint|remove-breakpoint",
    "source": "entry_point:path",
    "line": 1
}
```

### Запрос деталей локального значения

```json
{
    "type": "get-value",
    "frame": 0,
    "local": 1,
    "path": ["path", "to", 1, "value"]
}
```

- `frame` — индекс фрейма стека вызовов (индексация от самого последнего вызова)
- `local` — индекс локальной переменной (на основе трассировки стека события `paused`)
- `path` — сегменты пути запрашиваемого значения. Пример: `['a', 'b', 5]` — это `local_variable.a.b[5]`

Ответ:

```json
{
    "type": "value",
    "frame": 0,
    "local": 1,
    "path": ["path", "to", 1, "value"],
    "value": "само значение"
}
```

Пример: фактическое значение — таблица:

```lua
{a=5, b="test", 2={}}
```

Тогда `value`:

```json
{
    "a": {
        "type": "number",
        "short": "5"
    },
    "b": {
        "type": "string",
        "short": "test"
    },
    "1": {
        "type": "table",
        "short": "{...}"
    }
}
```

## От сервера к клиенту

### Сигналы ответа

```json
{
    "type": "success|resumed"
}
```

### Событие паузы

```json
{
    "type": "paused",
    "?reason": "breakpoint|exception|step",
    "?message": "...",
    "?stack": [
        {
            "?function": "имя функции",
            "source": "имя источника",
            "what": "what",
            "line": 1,
            "locals": [
                "name": {
                    "type": "тип локальной переменной",
                    "index": 1,
                    "short": "краткое значение",
                    "size": 0
                }
            ]
        }
    ]
}
```

# Спецификация формата VEC3

Двоичный формат 3D-моделей.

Порядок байтов: little-endian

## Синтаксис

```cpp
enum AttributeType:uint8 {
    POSITION = 0,
    UV,
    NORMAL,
    COLOR,
};
sizeof(AttributeType) == 1;

struct VertexAttribute {
    AttributeType type; // тип данных определяется по типу атрибута
    uint8 flags;
    uint32 size;
    float data[]; // если сжато, первые 4 байта сжатых данных — размер после декомпрессии
};
sizeof(VertexAttribute) == 6; // + динамический массив данных

struct Mesh {
    uint32 triangle_count; // количество треугольников сетки
    uint16 material_id;
    uint16 flags;
    uint16 attribute_count;
    VertexAttribute attributes[];
    uint8 indices[]; // если сжато, первые 4 байта сжатых данных — размер сжатого буфера
};
sizeof(Mesh) == 10; // + динамический массив атрибутов + динамический массив индексов

struct Model {
    uint16 name_len;
    vec3 origin;
    uint32 mesh_count;
    Mesh meshes[];
    char name[];
};
sizeof(Model) == 18; // + динамический массив Mesh + длина имени

struct Material {
    uint16 flags;
    uint16 name_len;
    char name[];
};
sizeof(Material) == 4; // + строка динамического размера

struct Header {
    char[8] ident;   // "\0\0VEC3\0\0"
    uint16 version;  // текущая — 1
    uint16 reserved; // 0x0000
};
sizeof(Header) == 12;

struct Body {
    uint16 material_count
    uint16 model_count
    Material materials[];
    Model models[];
};
sizeof(Body) == 4; // + динамический массив моделей + динамический массив материалов

```

\* данные вершин: позиции глобальны. Начало координат модели используется для преобразования в локальные.

вершина — набор индексов записей секции данных вершин, разделённых шагом, начиная с 0 (первая запись секции).

Пример: в файле с секциями (координаты, текстурные координаты, нормаль) вершина — набор из 3 индексов, упорядоченных
так же, как секции хранятся в файле.

## Теги секции данных вершин

Все секции опциональны.

| Значение | Имя                   | Шаг (байт)  | Описание                      |
| -------- | --------------------- | ----------- | ----------------------------- |
| %x01     | Координаты            | 12          | позиция вершины               |
| %x02     | Текстурные координаты | 8           | текстурные координаты вершины |
| %x03     | Нормали               | 12          | вектор нормали вершины        |
| %x04     | Цвет                  | 16          | цвет вершины RGBA (0.0–1.0)   |

Флаги VertexAttribute:

| Значение | Имя                |
| -------- | ------------------ |
| %x01     | Сжатие ZLib        |

## Сетка (Mesh)

Флаги сетки:

| Значение | Имя                                            |
| -------- | ---------------------------------------------- |
| %x01     | Сжатие индексов ZLib                           |
| %x02     | Использовать 16-битные индексы вместо 8-битных |

## Материал

Флаги материала:

| Смещение бита | Описание        |
| ------------- | --------------- |
| 0             | Без тени        |
| 1–7           | Зарезервировано |

# Спецификация двоичного формата JSON

Версия формата: 1.0

Этот двоичный формат данных разработан для использования в качестве двоичной версии JSON в [ChromaForge-Cpp](https://github.com/Ezhovnik/ChromaForge-v2) и несовместим с [BSON](https://bsonspec.org/spec.html) из-за различий в синтаксисе элементов/записей и кодах типов.

## Базовые типы

Порядок байтов: little-endian

| Имя     | Размер    | Описание                           |
| ------- | --------- | ---------------------------------- |
| byte    | 1 байт    | 8-битное беззнаковое целое         |
| int16   | 2 байта   | 16-битное знаковое целое           |
| int32   | 4 байта   | 32-битное знаковое целое           |
| int64   | 8 байт    | 64-битное беззнаковое целое        |
| uint32  | 4 байта   | 32-битное беззнаковое целое        |
| float64 | 8 байт    | 64-битное число с плавающей точкой |

## Синтаксис (RFC 5234)

```bnf
file      = %x01 document / cdocument   содержимое файла
document  = uint32 (*entry) %x00        uint32 хранит количество байтов
                                        закодированного документа,
                                        включая размер uint32
entry     = cstring value
value     = %x01 document
          / %x02 (*value) %x00          список значений
          / %x03 byte                   8-битное целое
          / %x04 int16                  16-битное целое
          / %x05 int32                  32-битное целое
          / %x06 int64                  64-битное целое
          / %x07 float64                число
          / %x08 string                 строка в кодировке UTF-8
          / %x09 uint32 (*byte)         массив байтов
          / %x0A                        логическое «false»
          / %x0B                        логическое «true»
          / %x0C                        значение null
cdocument = %x1F %x8B (16*byte)         данные, сжатые gzip:
                                            %x01 document
cstring   = (*%x01-FF) %x00
string    = uint32 (*byte)              uint32 хранит количество байтов
                                        закодированной строки

float64   = 8byte
int64     = 8byte
uint32    = 4byte
int32     = 4byte
int16     = 2byte
byte      = %x00-FF
```

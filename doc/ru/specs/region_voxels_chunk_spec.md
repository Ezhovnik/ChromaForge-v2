# Воксельный чанк (версия 2)

ID и состояния разделены для повышения эффективности сжатия extRLE16.

Формат файла в BNF (RFC 5234):

```bnf
chunk    = (65536*uint16)  ID блоков
           (65536*uint16)  состояния блоков

uint16   = 2byte           16-битное беззнаковое целое (little-endian)
byte     = %x00-FF         8-битное беззнаковое целое
```

65536 — количество вокселей в чанке (16\*256\*16)

## Состояние блока

Состояние блока кодируется 16 битами:

- биты 0–2 (3) — индекс поворота блока;
- биты 3–5 (3) — биты сегмента блока;
- биты 6–7 (2) — зарезервированы;
- биты 8–15 (8) — пользовательские биты.
